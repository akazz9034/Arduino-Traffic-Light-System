
# Arduino Traffic Light System

## Project Overview
This project simulates a traffic signal using an Arduino Uno and three LEDs.

## Components Required
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- Resistors
- Breadboard
- Jumper wires

## Pin Connections
- Green LED: Pin 2
- Yellow LED: Pin 3
- Red LED: Pin 4

## Working Principle
The green LED turns on for 3 seconds, the yellow LED for 1 second, and the red LED for 3 seconds. This sequence repeats continuously.
